# AI Workspace

This directory stores all AI-oriented project context.

Purpose:
- improve AI collaboration;
- preserve project consistency;
- centralize prompts and rules;
- accelerate development.

### context/
Global project understanding.

### prompts/
Reusable prompts.

### rules/
Development standards.

### memory/
Project memory and evolution.

### agents/
