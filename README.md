# 🔧 DataForge
### Plataforma de Datasets Relacionais Sintéticos

> Gere ecossistemas de dados realistas com inteligência relacional — via prompts, storytelling e esquemas personalizados.

---

## 📌 Visão Geral

**DataForge** é uma plataforma nativa de IA para geração de datasets relacionais sintéticos e realistas.

Em vez de baixar datasets estáticos, os usuários podem criar ecossistemas de negócios completos utilizando:

- 💬 Prompts em linguagem natural
- 📖 Storytelling de negócios
- 🗂️ Esquemas personalizados
- 🧹 Simulação de dados sujos (*dirty data*)
- 🔗 Inteligência relacional

---

## ✨ Funcionalidades Principais

### 🏢 Geração Baseada em Cenários

Gere datasets a partir de narrativas de negócios.

**Exemplo:**
> *"Gere uma fintech brasileira com clientes, faturas, eventos de fraude e pagamentos atrasados."*

---

### 🔗 Geração de Datasets Relacionais

Gere conjuntos de dados conectados com:

- Relacionamentos PK/FK
- Distribuições realistas
- Consistência temporal
- Estruturas semelhantes às de ambientes enterprise

---

### 🧹 Dirty Engine

Controle o nível de realismo ou corrupção dos dados gerados.

| Nível | Descrição |
|---|---|
| `CLEAN` | Dados limpos e consistentes |
| `ANALYTICS` | Pequenas imperfeições analíticas |
| `ENGINEERING` | Inconsistências típicas de pipelines |
| `CHAOS` | Alta corrupção e dados corrompidos |

---

### 📦 Exportação de Datasets

**Formatos suportados:**
- CSV
- JSON

**Em breve:**
- Parquet
- Delta
- Avro

---

## 🎯 Objetivos do MVP

O MVP é focado em:

- Geração via prompts
- Geração de esquemas relacionais
- Geração de dados sintéticos
- Simulação de dados sujos
- Exportação de datasets
