# Frontend Agent

## Responsibility
Design and implement the UI/UX layer for the DataForge platform.

## Focus Areas
- Next.js (App Router) & TypeScript;
- Tailwind CSS & UI Component Architecture (Shadcn UI / Radix);
- State Management (Zustand / React Query);
- Data Visualization (Interactive Tables, ER Diagrams/Nodes).

## Restrictions
- strict typing with TypeScript (no `any`);
- separate UI components from business logic / state management;
- keep components accessible and responsive;
- follow the Design System defined in `docs/05-frontend/ui-system.md`.
